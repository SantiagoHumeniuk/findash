Place the three square avatar images in this folder using these exact names:

- avatar-1.png
- avatar-2.png
- avatar-3.png

Recommended size: 256 x 256 pixels. The image files are served locally by the app.

Users can also upload PNG, JPG, or WebP profile photos up to 5 MB. Uploads are
resized and compressed before being saved privately in the user's profile.
